# PokerDivinationGame
# 🔮 皇家聖三角 · 命運誠實占卜 (音效加強版)

一個基於 **C# 7.3 與 WinForms (Windows Forms)** 開發的撲克牌神祕學占卜輕量小遊戲。本專案採用經典的「聖三角占卜法」，透過數位洗牌與翻牌儀式，誠實且犀利地為玩家剖析所求之事的過去、現在與未來走向，並結合 Windows 內建的經典音效，打造沉浸式的命運解讀體驗。

---

## 🌟 核心特色

1. **經典聖三角牌陣 (The Holy Triangle)**
   - 一次依序抽解三張牌，分別高亮對應：
     - `❶ 過去`：事情發生的根源與潛在能量。
     - `🧭 現在`：當前所處的真實境遇與心理狀態。
     - `🎯 未來`：命運最終的走向預測。

2. **動態洗牌魔法特效**
   - 點擊「開始洗牌儀式」後，卡牌區會觸發 `Timer` 微秒級淡紫色動態閃爍動畫，模擬真實世界中調和命運能量的洗牌過程。

3. **雙向命運交響音效 (沉浸式體驗)**
   - 遊戲完美連動 Windows 系統隱藏的經典實體音效庫，在翻開第三張「未來走向」時觸發：
     - 🎉 **大吉/完美突破**：播放高亢華麗的 **Windows 登入成功交響樂** (`Windows Logon`)。
     - 😭 **大凶/面臨考驗**：播放經典綜藝感下降失落音 **硬體拔出提示音** (`Windows Hardware Remove`)，吹喇叭效果直接拉滿！
     - 🛑 **一般平穩結果**：播放沉穩的系統結束音 (`SystemSounds.Hand`)。

4. **地獄級誠實！三級嚴重度警報**
   - 針對代表刀刃與精神危機的**黑桃低點數牌 (2~7)**，解牌庫絕不拐彎抹角，會以最誠實的話語給予最嚴厲的警告，並在介面上以不同層次的**高亮紅色粗體**標示：
     - 🔴 **黑桃 2、3**：`烈火級大凶 — 腹背受敵` (深紅色)
     - 🔴 **黑桃 4、5**：`重度級中凶 — 陷入泥淖` (鮮紅色)
     - 🔴 **黑桃 6、7**：`輕中度小凶 — 暗流洶湧` (橘紅色)

5. **精心雕琢的古典視覺介面**
   - 全視窗採用復古典雅的米色背景 (`#F5F2EB`) 與深咖啡色、金色的現代感按鈕。
   - 尚未抽牌時會顯示精緻的**虛線卡牌定位框**；抽牌後則會即時渲染出具備高低防鋸齒細節、完美區分紅黑花色的精美撲克牌正面。

## 🛠️ 開發環境與架構

- **開發語言**：C# 7.3
- **視窗框架**：Windows Forms (.NET Framework)
- **視覺渲染**：`System.Drawing` (GDI+ 圓角矩形與抗鋸齒圖形繪製)
- **音效驅動**：`System.Media.SoundPlayer` / `System.Media.SystemSounds`
- **文字系統**：`RichTextBox` 動態字體色彩樣式排版

---

## 📂 程式碼結構說明 (`Form1.cs`)

為了完美兼容 **Visual Studio 設計工具 (Designer)**，程式碼架構經過特別優化：
1. **`Form1` 類別置頂**：確保 Visual Studio 設計工具雙擊開啟時能 100% 正常載入 UI 預覽，拒絕藍色報錯畫面。
2. **`InitializeGameComponents`**：全程式碼動態建構 UI，無需依賴繁重的設計工具 `.Designer.cs` 檔案，移交極其方便。
3. **資料與邏輯分離**：檔案底端定義了自訂的 `Card` 實體類別與 `Suit` 花色列舉，方便未來的解牌庫擴充。

## 🎮 操作指南

1. **啟動遊戲**：執行程式後，介面會提示「【 命運之輪 】請先點擊開始洗牌...」。
2. **開始洗牌**：點擊 **🃏 開始洗牌儀式** 按鈕，此時會響起系統提示音，且卡牌會進入淡紫色閃爍狀態。
3. **抽取過去與現在**：點擊 **🔮 翻開下一張**，依序翻開左邊與中間的牌，下方會同步產生對應的文字解讀，並伴隨清脆的「叮」聲。
4. **揭曉終極命運**：再次點擊 **🔮 翻開下一張**，右邊的「未來走向」將會翻開。此時系統會根據最後一張牌的花色點數判定好壞，**瞬間炸出對應的交響樂或失落吹喇叭音效**！

## 📝 備註與音效自我客製

程式中預設使用的是 Windows 系統路徑下的標準音效：
- 大吉路徑：`C:\Windows\Media\Windows Logon.wav`
- 大凶路徑：`C:\Windows\Media\Windows Hardware Remove.wav`

若您想換成自己下載的超震撼爆炸聲或卡通搞笑音效，只需將檔案轉為 `.wav` 格式，放入專案的 `bin\Debug\` 目錄下，並修改 `Form1.cs` 內 `PlayDestinySound` 函式中的檔案路徑即可！
